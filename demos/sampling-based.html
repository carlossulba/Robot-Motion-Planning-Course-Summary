Sampling-Based Algorithms

PRM (Probabilistic Roadmap) §8.3.1 / book §7.1

Sample free milestones, connect each to its k nearest neighbors, then search the resulting graph.

RRT (Rapidly-Exploring Random Tree) §8.5.1 / book §7.2.2

Grow a tree from q_start: sample a point, extend from the nearest tree node by a fixed step, keep it if collision-free.

RRT* §8.5.3 / book §7.2.2

RRT plus rewiring: every new node picks the lowest-cost nearby parent, and can steal nearby nodes from the tree if that shortens their path.

OBPRM (Obstacle-Based PRM) §8.3.2 / book §7.1

Bias milestones toward obstacle surfaces: find a colliding seed, walk to a free point, binary-search the boundary between them.

EST (Expansive-Spaces Trees) §8.4.2 / book §7.2.1

Grow a tree by picking sparsely-covered nodes to expand from, keeping a nearby candidate only if a local planner connects it back.

SBL (Single-query, Bi-directional, Lazy) §8.4.2 / book §7.2.3

Two EST-style trees grow with unverified edges; only when start and goal trees touch is the whole candidate path checked for collisions.

SRT (Sampling-Based Roadmap of Trees) §8.6 / book §7.2.1

Grow several small trees from random roots, then connect nearby trees with the same tree planner — merging into one roadmap wherever two trees touch.
