Cell Decompositions

Trapezoidal, Boustrophedon, and Quadtree decomposition, run against the exact same obstacles, start, and goal so the three decomposition styles are directly comparable.

Regenerates one shared obstacle world for all three panels below. Each panel's own Step / Play / Reset re-runs only that algorithm against the current world.

Trapezoidal Decomposition §7.1 / book §6.1

A vertical line is extended from every obstacle vertex, slicing free space into trapezoids. Path = adjacency-graph search + centroid/midpoint connectors.

Boustrophedon (Morse) Decomposition §7.2 / book §6.2

A slab boundary is only placed where the number of free-space intervals actually changes — far coarser than trapezoidal decomposition.

Quadtree Decomposition §7.4 / book §6.2

Recursively split a mixed region into 4 quadrants until each leaf is uniformly free or uniformly occupied — an approximate decomposition.
