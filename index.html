7 · Cell Decompositions

Trapezoidal Decomposition

§7.1 / book §6.1

A vertical line is extended from every obstacle vertex, slicing free space into trapezoids. Path = adjacency-graph search + centroid/midpoint connectors.

Try it live →

Boustrophedon (Morse) Decomposition

§7.2 / book §6.2

A slab boundary is only placed where the number of free-space intervals actually changes — far coarser than trapezoidal decomposition.

Try it live →

Quadtree Decomposition

§7.4 / book §6.2

Recursively split a mixed region into 4 quadrants until each leaf is uniformly free or uniformly occupied — an approximate decomposition.

Try it live →

8 · Sampling-Based Algorithms

PRM (Probabilistic Roadmap)

§8.3.1 / book §7.1

Sample free milestones, connect each to its k nearest neighbors, then search the resulting graph.

Try it live →

RRT (Rapidly-Exploring Random Tree)

§8.5.1 / book §7.2.2

Grow a tree from q_start: sample a point, extend from the nearest tree node by a fixed step, keep it if collision-free.

Try it live →

RRT*

§8.5.3 / book §7.2.2

RRT plus rewiring: every new node picks the lowest-cost nearby parent, and can steal nearby nodes from the tree if that shortens their path.

Other Sampling Strategies

Narrow-passage sampling heuristics — biasing where milestones land so a roadmap can actually find its way through thin gaps.

Gaussian Sampler

narrow-passage sampling

Sample q1 uniformly, q2 at a Gaussian offset from q1; keep the free one as a milestone only if exactly one of the pair is in collision.

Try it live →

Bridge Test

narrow-passage sampling

Sample two colliding configurations; keep their midpoint as a milestone only if the midpoint itself is collision-free.

Try it live →

GVD-Retraction Sampling

narrow-passage sampling

Sample a raw configuration, then retract it toward the nearest point of the Generalized Voronoi Diagram — the max-clearance skeleton that runs through every passage.

Try it live →

Visibility-Based Sampling

narrow-passage sampling

Keep a candidate milestone only if it sees a useful amount of free space not already visible from the existing roadmap (estimated on a coarse grid).
